# Exploración opcional

Usar esta carpeta para exploración y análisis. Trasladar a `src/bank_attrition/`
la lógica necesaria para preparar datos, entrenar, inferir y monitorear, de modo
que los procesos puedan ejecutarse mediante comandos o workflows.

Documentar la versión de datos y semilla. No versionar datos crudos, credenciales,
identificadores de clientes ni salidas extensas del notebook. Guardar artefactos
y resultados en los destinos del proyecto y enlazarlos desde la documentación.
